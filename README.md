# Word-like Document View

Локальный плагин Obsidian, который делает редактирование и чтение Markdown ближе к виду листа Word/Docxer: страница, поля, масштабирование и варианты оформления рабочей области.

## Статус

Рабочий локальный плагин. Репозиторий вынесен отдельно от Obsidian Vault, чтобы стили и логика плагина не смешивались с заметками.

## Установка

Папка плагина должна находиться в:

```text
.obsidian/plugins/word-like-document-view
```

В текущем хранилище Obsidian эта папка подключена через junction-ссылку на отдельный репозиторий:

```text
S:/Users/HiDespondency/Documents/Obsidian Plugins/word-like-document-view
```

## Состав

- `manifest.json` - описание плагина для Obsidian.
- `main.js` - рабочий код плагина и настройки.
- `styles.css` - стили страницы, панелей, подсветок и режимов оформления.

## Архитектура

Плагин разделён на три уровня:

1. **Состояние плагина** — `main.js` управляет одним набором классов на `body` (`BODY_CLASS`) и снимает их вместе с inline-переменными при отключении.
2. **Токены оформления** — начало `styles.css` содержит единый контракт `--docxer-md-*`. Токены доступны только при активном классе плагина и могут получать значения темы через `var(--wrapped-*, fallback)`.
3. **Адаптер Obsidian** — селекторы нативных областей (`markdown-preview-view`, `markdown-source-view`, `cm-table-widget`, PDF и панели) находятся под классом состояния Word-like. Это единственная зона, где допускается `!important`: она нужна для приоритета над встроенными стилями Obsidian и сторонних тем.

Собственные элементы плагина (`.word-like-toolbar` и его дочерние классы) не используют `!important`. Таблицы, свойства, ссылки, callout-блоки и окружение документа оформляются отдельными секциями, но используют общие токены вместо повторяющихся цветов и размеров.
